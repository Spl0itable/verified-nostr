Were you looking up an address?

Nostr Addresses aren't web pages — they resolve through the NIP-05 endpoint. To check whether a username is registered:

https://nostraddress.com/.well-known/nostr.json?name=username

An unregistered name returns {"names":{}}. See the API reference.
